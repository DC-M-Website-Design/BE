# DC&M Backend

DC&M 웹사이트의 서버 코드를 위한 별도 레포지토리입니다.
백엔드를 구현할 경우 사용자 지정 기술 스택인 Spring을 사용합니다.

현재 와이어프레임 반영 작업은 `../FE`의 프런트엔드에 구현되어 있으며,
이 레포지토리에 서버나 임의의 API 구현을 추가하지 않았습니다.

## 현재 기능 경계

- 동아리 소개·구성원·연혁·활동·공지 표시는 FE의 콘텐츠 데이터를 사용합니다.
- 동아리 지원은 Google 폼으로 안내하는 흐름입니다. 폼 URL은 아직 미정입니다.
- 문의 채널은 `hansung.dcnm@gmail.com`이며 FE의 Q&A 폼은 미리보기입니다.
- 로그인은 FE의 체험용 프로필입니다. 실제 회원 인증과 권한 관리는 구현 전입니다.

Spring API를 추가할 때 회원 인증·게시글 관리·문의 저장의 실제 요구사항과
요청/응답 형식을 먼저 정의하고 FE와 연결하면 됩니다.
FE의 개발용 `/api` 프록시는 `http://127.0.0.1:8080`을 대상으로 설정되어 있습니다.

FE와 BE의 Git 저장소는 별도로 유지합니다.
